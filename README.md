# Meal Aggregator

## Про проєкт
Сучасний ритм життя ускладнює щоденне планування раціону та змушує витрачати забагато часу на пошук відповідних рецептів. 

**Meal Aggregator** розв'язує цю проблему шляхом автоматичного збору та систематизації кулінарних даних із відкритих API в єдиній зручній системі. Продукт орієнтований на домашніх кулінарів, студентів та людей із обмеженим часом, які прагнуть швидко підбирати страви під свій графік і наявні продукти. 

Для повноцінної роботи системи використовуються дані про назви страв, покрокові інструкції, час приготування, а також детальний перелік та поширеність інгредієнтів. Аналізуючи ці параметри, сервіс дозволяє ефективно фільтрувати рецепти за доступністю складників та швидкістю готування, мінімізуючи харчові відходи. У результаті користувач отримує розумного помічника, який перетворює хаотичний пошук рецептів на швидкий та прогнозований процес.
